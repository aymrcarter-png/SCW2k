# Match card graphics

One folder per show. Name each folder `<show>-YYYY-MM-DD` using the show name
(lowercase, dashes) and the event date. That keeps every week distinct and sorted.

```
media/matches/
  rumble-in-the-bronx/        big events get their own name
  showdown-2026-09-26/        weekly SCW Showdown, by date
  showdown-2026-10-03/
  showdown-2026-10-10/
  showdown-2026-10-17/
```

Drop that week's match graphics inside the matching folder. Any image name is
fine — `match-1.jpg`, `main-event.jpg`, etc. Then send them here (or push) and
they'll be added to the Events page.

NOTE: the original Rumble graphics still live directly in this folder
(`rumble-1.jpg` … `rumble-5.jpg`) and are referenced by `events.html`. Leave
them where they are so the live page doesn't break.
